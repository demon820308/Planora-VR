# Planora 产品需求文档（PRD）

## 1. 项目概述

**项目名称：** Planora  
**技术栈：** Vite + React + TypeScript + Pannellum + PaddleOCR  
**定位：** 用于本地 VR 预览、房间切换和户型图导航的轻量化展示站点

Planora 面向“单户型、单风格”的项目展示。  
它不依赖固定房间模板，而是通过白底户型导航图识别热区、识别房间名称，再将结果直接用于首页浏览与效果图展示。

---

## 2. 产品目标

1. 用一张白底户型导航图快速生成房间热区结构。
2. 自动识别房间名称，并直接作为首页房间名称使用。
3. 批量导入当前项目风格的房间效果图。
4. 通过 SVG 热区图和 360 全景实现房间切换。
5. 支持将当前结果导出为可离线打开的 zip 包。

---

## 3. 当前核心能力

### 3.1 设置页

设置页入口：

```text
/?lab=floorplan
```

支持：

- 上传白底户型导航图
- 自动分析封闭房间区域
- 生成 SVG 热区
- 自动识别热区名称（PaddleOCR）
- 手动修改热区名称
- 启用 / 禁用热区
- 选择当前项目风格
- 批量导入效果图文件夹
- 一键应用到首页
- 清除首页应用
- 导出离线包
- 使用帮助弹层

### 3.2 首页

首页支持：

- 当前风格显示
- 房间列表切换
- 360 全景展示
- `yaw / pitch / fov` 指标显示
- SVG 户型热区图导航
- 左下角展示户型图
- 户型图放大预览

### 3.3 离线导出

支持导出：

```text
planora-{风格名}-offline.zip
```

离线包特性：

- 解压后双击 `index.html` 即可查看
- 已内嵌当前导出时所需的图片资源
- 包含首页查看能力
- 不包含设置页与编辑能力

## 4. 使用流程

### 4.1 户型热区识别流程

1. 上传白底户型导航图
2. 自动分析封闭房间区域
3. 生成 SVG 热区
4. 识别房间名
5. 手动修正少量命名
6. 关闭不需要进入首页的热区

### 4.2 效果图导入流程

1. 选择当前项目风格
2. 批量导入效果图文件夹
3. 通过“文件名主干 = 房间名”自动匹配
4. 导入展示户型图（可选）

### 4.3 首页同步流程

1. 点击“一键应用到首页”
2. 首页同步：
   - 房间名称
   - 启用状态
   - SVG 热区图
   - 当前风格
   - 房间效果图
   - 展示户型图

### 4.4 离线交付流程

1. 完成首页配置
2. 导出离线包
3. 解压后打开 `index.html`
4. 离线查看当前项目

## 5. 户型图要求

推荐输入图：

- 白底
- 黑灰线条
- 房间边界闭合
- 房间名称尽量写在房间中部
- 尽量减少尺寸线和复杂干扰

用途说明：

- 这张图用于识别房间热区和房间名称
- 不要求与首页左下角展示户型图是同一张图

---

## 6. 房间命名逻辑

当前逻辑：

- OCR 识别出的房间名称，直接作为热区正式名称
- 首页左侧房间列表直接使用这些名称
- 没有名字的热区，不进入首页
- 已禁用的热区，不进入首页

也就是说：

- 不再依赖固定房间模板
- 房间体系由当前户型图驱动

## 8. 效果图导入规则

### 8.1 房间效果图命名

匹配规则：

```text
文件名主干 = 房间名
```

例如识别出的房间名为：

- 主卧A
- 客厅
- 书房

则可导入：

```text
主卧A.jpg
客厅.png
书房.webp
```

支持扩展名：

- jpg
- jpeg
- png
- webp

系统只看主文件名，不强制某一种后缀。

### 8.2 展示户型图命名

如果文件夹中包含：

```text
户型图.png
```

或：

```text
户型图.jpg
```

则作为首页左下角展示户型图使用。

说明：

- 这张展示图不参与底部热区图叠加
- 因此不会影响热区对齐

### 8.3 导入失败提示

系统会提示：

- 未匹配文件
- 缺失房间

提示语：

```text
请检查效果图命名
```

## 10. 数据与存储

### 10.1 浏览器本地存储

当前导入的房间效果图和展示户型图保存到浏览器本地：

- 无需后端
- 适合本地演示和静态部署
- 更换浏览器、设备或地址后需要重新导入

### 10.2 首页配置数据

首页读取：

- 热区轮廓
- 房间名
- 启用状态
- 预览底图信息

这些数据由设置页一键写入本地配置。

### 10.3 离线包

离线包内嵌：

- 当前风格名
- 房间列表
- 热区 polygon
- 当前首页所需图片资源
- 离线查看脚本与样式

## 11. 技术实现要点

### 11.1 热区识别

- 通过图像分析识别封闭区域
- 输出多边形点位
- 生成 SVG 热区图

### 11.2 OCR 识别

- 使用 `@paddleocr/paddleocr-js`
- 读取户型图中的房间文字
- 将识别结果分配到热区

### 11.3 360 全景展示

- 使用 `Pannellum`
- 支持鼠标拖动和缩放
- 首页和离线包都提供查看能力

### 11.4 离线导出

- 使用 `JSZip`
- 生成 zip 包
- 输出一个仅包含首页查看能力的离线站点
- 图片资源以内嵌形式导出，避免 `file://` 读取限制
