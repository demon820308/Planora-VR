# Planora

> 用于本地 VR 预览、房间切换和户型图导航。

[在线体验](https://planora-vr.netlify.app/)

---

## 项目简介

Planora 是一个面向户型展示与全景浏览的轻量站点。  
它不依赖固定房间模板，而是让每个项目都可以通过一张白底户型导航图，快速生成自己的房间结构与浏览入口。

整个流程更接近“项目驱动”而不是“模板驱动”：

- 识别户型图热区
- 识别房间名称
- 批量导入当前风格效果图
- 一键同步到首页展示

适合：

- 样板间网页演示
- 房地产 / 家装方案展示
- image2 效果图快速落地成站点
- 单户型、单风格的 VR 看房页面

## 使用流程

### 1. 上传白底户型导航图

在设置页上传一张白底、边界闭合清晰的二维户型图。

### 2. 自动识别热区

系统会分析封闭房间区域，生成 SVG 热区。

### 3. 自动识别房间名

点击 `自动识别热区名称`，由 PaddleOCR 读取房间文字。  
识别结果会直接成为首页房间名。

### 4. 选择当前项目风格

当前版本首页只显示一个风格。  
设置页选中的风格，就是首页展示的风格。

### 5. 批量导入效果图文件夹

识别出房间名后，即可导入当前风格的整套图片文件夹。

### 6. 一键应用到首页

应用后，首页会同步：

- 房间名称
- 热区轮廓
- 可点击状态
- 底部 SVG 热区图

## 文件夹导入规则

### 房间效果图命名

系统按“文件名主干 = 房间名”匹配图片。

例如识别出的房间名是：

- `主卧A`
- `客厅`
- `书房`

那么文件夹内应包含：

```text
主卧A.jpg
客厅.png
书房.webp
```

支持格式：

- `jpg`
- `jpeg`
- `png`
- `webp`

### 展示户型图命名

如果文件夹中包含以下任一文件：

```text
户型图.png
户型图.jpg
```

系统会将它作为首页左下角的展示户型图。

### 说明

- 没有名字的热区不会进入首页
- 已禁用的热区不会进入首页房间列表
- 文件名和房间名不一致时，系统会提示检查命名

## 首页结构

### 左侧栏

- 当前项目风格

- 当前状态
- 展示户型图

### 主视图区

- SVG 热区导航

- 线框索引
- `放大SVG热区图`

## 数据存储说明

当前导入的效果图和展示户型图，保存在浏览器本地。  
这意味着：

- 在当前浏览器中导入后可以直接使用
- 更换浏览器、设备或部署地址后，需要重新导入

这种方案的好处是：

- 无需后端
- 适合本地演示
- 适合免费静态部署
- 项目落地速度快
