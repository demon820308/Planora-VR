# Planora

> 用于本地 VR 预览、房间切换和户型图导航。

Planora 是一个基于 `Vite + React + TypeScript + Pannellum + PaddleOCR` 的全景看房站点。  
它的核心目标不是做“固定模板式样板间”，而是让每一个户型都能通过：

- 白底户型导航图识别热区
- OCR 识别房间名称
- 批量导入同风格效果图
- 一键同步到首页浏览

快速得到一个可演示、可切房间、可看全景的网页版本。

---

## 功能概览

- 360° 全景房间浏览
- 户型图热区导航
- 房间名称自动识别
- 单风格项目展示
- 批量导入效果图文件夹
- 本地浏览器存储导入图片
- 首页底部 SVG 热区图放大预览
- 左侧展示户型图放大预览

```bash

```

```text
http://localhost:5173
```

设置页入口：

```text
http://localhost:5173/?lab=floorplan
```

## 使用流程

### 1. 上传白底户型导航图

在设置页上传一张白底、闭合边界清晰的二维户型图。

### 2. 自动识别热区

系统会分析封闭房间区域，生成 SVG 热区。

### 3. 自动识别房间名

点击 `自动识别热区名称`，由 PaddleOCR 识别房间文字。  
识别后的名字会直接成为首页房间名。

### 4. 选择当前项目风格

当前版本首页只显示一个风格。  
你在设置页选择哪个风格，首页就显示哪个风格。

### 5. 批量导入效果图文件夹

在识别出房间名后，可以批量导入当前风格的效果图文件夹。

命名规则：

- 文件名主干必须等于房间名
- 不区分扩展名
- 支持 `jpg / jpeg / png / webp`

例如识别出的房间名为：

- `主卧A`
- `客厅`
- `书房`

那么文件夹中应包含：

```text
主卧A.jpg
客厅.png
书房.webp
```

### 6. 导入展示户型图

如果文件夹中包含以下任一文件：

- `户型图.png`
- `户型图.jpg`

系统会将它作为首页左侧展示户型图使用。

### 7. 一键应用到首页

点击 `一键应用到首页` 后，首页会同步：

- 热区轮廓
- 房间名称
- 可点击状态
- 底部 SVG 热区图

## 文件夹导入规则

### 房间效果图

```text
{房间名}.jpg
{房间名}.jpeg
{房间名}.png
{房间名}.webp
```

### 展示户型图

```text
户型图.png
户型图.jpg
```

### 说明

- 没有名字的热区不会出现在首页
- 已禁用的热区不会出现在首页房间列表
- 如果文件名和房间名不一致，系统会提示检查命名

## 首页交互

### 左侧栏

- 当前项目风格
- 房间列表
- 当前状态
- 展示户型图

### 主视图区

- 360 全景浏览
- `yaw / pitch / fov` 状态显示
- 左上角缩放与全屏控件

### 底部户型图区

- SVG 热区导航
- 当前房间高亮
- 线框索引
- `放大SVG热区图`

## 数据存储说明

当前导入的效果图和展示户型图，保存在浏览器本地。

也就是说：

- 本地浏览器里导入成功后可以直接使用
- 换浏览器、换设备、换部署地址后，需要重新导入

这是一种轻量、免后端的当前方案，适合：

- 本地演示
- 快速交付
- 免费静态站点部署

当前项目已适配静态部署，推荐直接部署到：

- `Vercel`

- 构建命令：`npm run build`

## 当前适用场景

Planora 适合：

- 单个户型的网页展示
- 样板间 / 效果图项目快速可视化
- 方案汇报演示
- 线上可访问的 VR 看房页面

它尤其适合“每个项目户型都不同”的场景，因为首页房间不是写死的，而是由当前识别结果驱动。
